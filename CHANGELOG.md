# Changelog

All notable changes to AmbientBar are listed here. Versions follow [Semantic Versioning](https://semver.org/).

## [0.2.0] - 2026-10-24

- **Favorites:** star any track to pin it in a Favorites list at the bottom of the panel. Click a favorite to play it.
- **Volume slider** in the panel. Click the speaker icon to mute.
- **In-app updates:** pick *Update to vX* in the tray menu to download, verify and install the new version. AmbientBar then restarts and keeps playing where it was.
- Tray menu: *Check for updates*

## [0.1.1] - 2026-10-24

- The tray menu shows a notice when a newer version is available
- Hovering the tray icon shows the version number

## [0.1.0] - 2026-10-24

First release.

- Slim bar docked above the taskbar, with an expandable search and queue panel
- Audio-only streaming of YouTube videos through yt-dlp
- Plain-text search (titles and lengths), plus pasting a video or playlist link
- Windows media controls: media keys, headset buttons and the media flyout with thumbnail
- Queue with repeat; saves the queue, current track, position and volume
- Gets a fresh stream link when one expires during a long track
- Tray icon (show/hide, play/pause, next, quit) and a notice when a new version is available
